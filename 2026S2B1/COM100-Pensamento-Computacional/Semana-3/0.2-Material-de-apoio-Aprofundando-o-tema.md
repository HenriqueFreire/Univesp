## 🎨 Princípios de Design de Ambientes Criativos

O Guia de Computação Criativa de Harvard estabelece que bons ambientes de programação para iniciantes devem possuir três características arquiteturais:

1. **Piso Baixo (*Low Floor*):** Deve ser extremamente fácil para um iniciante começar a criar algo funcional logo nos primeiros minutos (ex.: encaixar dois blocos e ver o personagem se mover e miar).
2. **Teto Alto (*High Ceiling*):** O ambiente deve ser suficientemente poderoso para permitir a construção de projetos altamente sofisticados com o passar do tempo (jogos complexos, simulações de física, processamento de áudio).
3. **Paredes Amplas (*Wide Walls*):** Deve suportar uma imensa diversidade de tipos de projetos (desde histórias interativas, cartas animadas, videoclipes musicais, até jogos de RPG e ferramentas pedagógicas de matemática).

## 📍 Coordenadas e Orientação no Palco do Scratch

Para posicionar qualquer elemento visual no palco:
- O palco do Scratch possui dimensões de **480 pixels de largura** por **360 pixels de altura**.
- O ponto central exato do palco é a origem cartesiana $(X = 0, Y = 0)$.
- O eixo horizontal ($X$) varia de $-240$ (extremo esquerdo) até $+240$ (extremo direito).
- O eixo vertical ($Y$) varia de $-180$ (base inferior) até $+180$ (topo superior).
- A direção padrão do personagem é $90^\circ$ (voltado para a direita). $0^\circ$ aponta para cima, $180^\circ$ para baixo e $-90^\circ$ para a esquerda.
