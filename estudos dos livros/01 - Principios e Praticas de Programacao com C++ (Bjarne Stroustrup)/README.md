# 📘 Princípios e Práticas de Programação com C++
**Autor:** Bjarne Stroustrup  
**Fase no Plano:** Fase 1 (Fundação em Programação & Sistemas)  
**Disciplinas UNIVESP Relacionadas:** *Algoritmos e Programação de Computadores*, *Pensamento Computacional*

---

## 🎯 Objetivos de Estudo
- Compreender a base de algoritmos e pensamento computacional através do C++.
- Entender fluxo de controle, funções e organização modular de código.
- Dominar o modelo de memória: *Stack* vs *Heap*, ponteiros, referências e RAII (*Resource Acquisition Is Initialization*).
- Aprender a utilizar a Standard Template Library (`std::vector`, `std::string`, algoritmos e iteradores).
- Desenvolver hábitos de engenharia de software para código robusto, testável e de alto desempenho.
