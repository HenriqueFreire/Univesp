## 2. Como funciona o trabalho em grupo

- **O trabalho do grupo não é uma divisão de tarefas:** A proposta não é cada integrante fazer um pedaço e alguém juntar tudo no fim. O que se pede é uma reflexão construída em conjunto: vocês comparam o que cada um escreveu sozinho, discordam quando for o caso e chegam juntos a uma leitura integrada.
- **Cada um chega ao grupo com o seu trabalho pronto:** O trabalho individual vem antes, e é ele que você leva para a conversa.
- **O tamanho do grupo não altera a atividade:** A atividade foi desenhada para funcionar igualmente bem com dois ou com cinco participantes.
- **Os colegas chegam em momentos diferentes:** A etapa prática abre para cada pessoa quando ela conclui os quatro primeiros módulos. Se chegou primeiro, registre o que escreveu para iniciar a discussão.
- **O representante da quinzena:** O grupo escolhe uma pessoa para representá-lo a cada quinzena. Apenas o representante envia o trabalho do grupo e recebe o trabalho de outro grupo para leitura.
- **A entrega vale para todos que participaram:** A entrega é registrada para todos os integrantes participantes.
